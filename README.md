# VXV Compagnon

Versions publiées du compagnon de la guilde VXV (WoW Forever) : il relie le jeu au site de la guilde.

- Windows : `VXV-Compagnon-Setup.exe`
- Mac : `VXV-Compagnon.dmg`

Téléchargement et installation : page « Compagnon » du site de la guilde. Le compagnon installé se met à jour depuis ce dépôt.

Le code est dans un dépôt privé ; ce dépôt ne contient que les versions publiées.
